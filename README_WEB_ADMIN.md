# لوحة التحكم السحابية - إدارة خدمات النظافة التشغيلية (Web & Desktop Dashboard)

لوحة تحكم إدارية متكاملة واحترافية تعمل على أجهزة الكمبيوتر واللابتوب، وتدعم **التثبيت كبرنامج مستقل (Desktop App)**، ومربوطة مباشرة بسحابة **Firebase Firestore** المشتركة والمتزامنة مع تطبيق الجوال بنسبة 100%.

---

## 🔐 1. كيفية حفظ وتأمين كلمة المرور كـ GitHub Secret (Security & GitHub Actions)

لحماية كلمة المرور ومنع وجودها داخل كود الـ HTML أو في المستودع البرمجي، تم إعداد سير عمل آلي (**GitHub Action Workflow**) يقوم بتشفير كلمة المرور عبر `SHA-256` وحقنها آلياً أثناء النشر دون أن تظهر كلمة المرور الصريحة أبداً في الكود.

### 📋 خطوات إضافة الأسرار (Secrets) في GitHub:
1. افتح مستودع مشروعك على موقع **GitHub**.
2. اذهب إلى تبويب **الإعدادات (Settings)** في الأعلى.
3. من القائمة الجانبية اليسرى، اضغط على **Secrets and variables** ثم اختر **Actions**.
4. اضغط على الزر الأخضر **New repository secret** وأضف الرمزين التاليين:
   - **الرمز الأول (كلمة مرور المدير):**
     - **Name:** `ADMIN_DASHBOARD_PASSWORD`
     - **Secret:** اكتب كلمة المرور السرية التي تريدها (مثال: `CleanPro#2026@Pass`).
   - **الرمز الثاني (مفتاح ذكاء اصطناعي / Gemini API Key):**
     - **Name:** `GEMINI_API_KEY` (أو `GEMINI_API_KEY1`)
     - **Secret:** الصق مفتاح Google Cloud / Gemini API السري الخاص بك.

### ⚙️ سير العمل التلقائي (GitHub Actions Workflow):
- ملف سير العمل:  
  `/.github/workflows/deploy-admin-dashboard.yml`
- عند كل عملية رفع (`git push`) أو تشغيل يدوي، يقوم الـ Action بالآتي:
  1. قراءة `ADMIN_DASHBOARD_PASSWORD` وتوليد تجزئة أمان مشفرة بصيغة **SHA-256 Hash**.
  2. قراءة `GEMINI_API_KEY` وحقنه بأمان أثناء عملية البناء والنشر.
  3. نشر لوحة التحكم على **GitHub Pages** بنسخة خالية 100% من أي أسرار صريحة ومحمية بالكامل.

### 🛡️ الأمان المحلي (بدون GitHub):
- لا توجد أي كلمة مرور أو مفتاح API مكشوف في كود الـ HTML أو JavaScript نهائياً!
- في أول تشغيل محلي، يمكنك إنشاء كلمة مرور المدير وإدخال مفتاح الـ API في خانة الإعدادات المشفرة، ويتم حفظهما محلياً في متصفحك بشكل آمن وخاص.

## 💻 2. تثبيت لوحة التحكم في الكمبيوتر كبرنامج مستقل (PWA Desktop App)

يمكنك الآن تثبيت لوحة التحكم على جهاز الكمبيوتر أو اللابتوب (نظام Windows أو Mac) لتعمل مثل أي برنامج مثبت (Desktop Application) بنافذة مستقلة وأيقونة على سطح المكتب وشريط المهام بدون أشرطة المتصفح.

### 📲 خطوات التثبيت:

#### الطريقة الأولى (من داخل اللوحة بضغطة زر):
1. افتح لوحة التحكم في متصفحك (يفضل **Google Chrome** أو **Microsoft Edge**).
2. ستجد زراً أعلى الشاشة باللون الفيروزي بعنوان: **«💻 تثبيت في الحاسوب كبرنامج»** (وكذلك في تبويب «الإعدادات والأمان»).
3. اضغط على الزر، ثم اضغط على **تثبيت (Install)** في النافذة المنبثقة.
4. سيتم فوراً تثبيت البرنامج على جهازك وإضافة أيقونة مخصصة له على سطح المكتب وقائمة البرامج (Start Menu).

#### الطريقة الثانية (من شريط عنوان المتصفح):
1. في متصفح Chrome أو Edge، انظر إلى أقصى يمين شريط العنوان بالأعلى.
2. ستظهر أيقونة كمبيوتر صغيرة أو علامة زائد (**🖥️** أو **➕**).
3. اضغط عليها واختر **«تثبيت التطبيق (Install App)»**.

## 📊 3. الميزات والأقسام المتوفرة

1. **🏢 مواقع العمل والمشاريع:**
   - تعديل أي موقع عمل بمجرد الضغط على سطره في الجدول أو النقر على «✏️ تعديل».
   - إضافة وحذف المواقع، تصدير إلى Excel، واستيراد ملفات Excel/CSV.

2. **👷 العمالة والمشرفين:**
   - تعديل بيانات أي موظف أو مشرف بالضغط على سطره.
   - تصدير واستيراد كشوفات العمالة عبر Excel/CSV.

3. **📅 كشف الحضور والانصراف:**
   - أزرار سريعة لاختيار (اليوم / أمس / تحضير الكل).
   - تعديل الحضور مباشرة في الخلايا أو عبر نافذة التفاصيل.
   - تصدير كشف الحضور اليومي إلى Excel، ورفع الحضور من Excel أو Google Sheets.

4. **📦 المخزون والمواد:**
   - تنبيه فوري باللون الأحمر عند نقص المواد ووصولها للحد الأدنى.
   - زر مخصص لتحميل **«📄 قالب Excel جاهز لإضافة المخزون»** (`قالب_إضافة_المخزون_والمواد.xlsx`).
   - استيراد وتصدير كامل المخزون مع السحابة.

5. **💰 المالية والفواتير:**
   - تسجيل المصروفات وإصدار الفواتير مع حساب تلقائي لضريبة القيمة المضافة 15% وحالة السداد.
   - تصدير تقرير مالي كامل متعدد الأوراق (ورقة مصروفات وورقة فواتير).

6. **⚙️ الإعدادات والأمان والنسخ الاحتياطي:**
   - تغيير كلمة المرور بأمان، وفحص الاتصال الحي بـ Firebase Firestore.
   - تصدير واستعادة نسخ احتياطية كاملة بصيغة JSON.
